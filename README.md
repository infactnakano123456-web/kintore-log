# 筋トレログ

iPhoneのホーム画面に追加して使う、オフライン対応の筋トレ記録アプリです。

記録の流れと種目一覧は、筋トレMEMOに合わせています。

- **ホーム**：
  - 今月のカレンダーと、合計負荷量（7日間・28日間・総合計）を表示します。7日間には週ごとのバーも付きます。
  - MONTHLY ARCHIVE と、期間を指定した合計負荷量も見られます。
- **記録**：日の画面（合計種目数・セット数・レップ数・負荷量）→ ＋ →「種目を選択」（部位ごと）→ セット入力画面、の順に進みます。
  - セット入力画面には、休憩タイマー、前回の記録（Last Record）とそのコピー、自己ベストがあります。
  - 重さ・回数・メモは行の中で直接入力します。↪ で上のセットと同じ値にでき、補助のチェックも付けられます。
  - 有酸素（距離・時間・kcal）にも対応しています。
- **履歴**：月のカレンダーで記録日を確認できます。左右スワイプで月を移動します。
- **分析**：
  - 種目ごとの推移（推定1RM・最大重量・総負荷・レップ・セット数）を、折れ線・棒・点で表示します。
  - 自己ベスト、月ごとの推移（部位別の積み上げ）、部位別の割合も見られます。
- **AI出力**：その日・月・期間・全期間の記録をJSONにして、コピーまたは共有します。AIへの相談文を先頭に付けることもできます。
- **設定**：バックアップ（JSON）、取り込み（JSON・CSV）、種目の名前変更・部位設定・統合ができます。

記録は端末内（localStorage）にだけ保存し、サーバーには送りません。

## 使い方（iPhone）

1. SafariでアプリのURLを開き、共有ボタン →「ホーム画面に追加」を選びます。
2. ホーム画面のアイコンから起動します。2回目以降はオフラインでも動きます。
3. 設定 →「取り込み」で、筋トレMEMOから移行したJSON（またはCSV）を読み込みます。
4. ときどき、設定 →「バックアップ」でファイルAppやiCloud Driveに保存してください。

## 計算式

- 推定1RM（RM）＝ 重量 × (1 + 回数 / 40)。筋トレMEMOと同じ式です。
- 総負荷 ＝ 重量 × 回数 の合計です。

## 開発

ビルドは不要です（HTML/CSS/JavaScriptのみ、外部ライブラリなし）。

```sh
python3 -m http.server 8765        # http://localhost:8765 で確認
swift tools/make_icons.swift icons  # アイコンを作り直す
python3 tools/make_initial.py <筋トレMEMO_記録.csv> private/kintore_initial.json  # 移行用JSON
```

アプリを更新したら、`sw.js` の `CACHE` の番号を上げてください。iPhone側で新しい版に切り替わります。

`private/` には個人の記録が入るため、リポジトリには含めません（.gitignore）。
